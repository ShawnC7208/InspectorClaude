# Skill Recommender

Turn repeated Claude usage patterns into reusable assets.

## Recommend A Skill When

- The same prompt pattern appears repeatedly.
- The user repeats a review checklist.
- The user repeatedly asks for a specific output format.
- A workflow has stable steps and review criteria.

## Recommend Project Instructions When

- The preference applies across a project.
- The user repeats tone, format, style, test, or review rules.
- Claude often needs the same project context.

## Recommend Hooks, Agents, Or MCP Tools When

- A repeated check can be automated.
- A role-specific workflow recurs.
- External lookup or integration repeats often.

## Output Shape

Provide:

- suggested name
- problem solved
- evidence summary
- draft behavior
- impact and effort

Do not create files unless the user asks.
